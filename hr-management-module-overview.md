# HR Management Module Documentation

## Overview
The HR Management module provides comprehensive human resource management capabilities across businesses → Allows complete workforce management including staff administration, attendance tracking, leave management, claims processing, event management, and detailed analytics with support for multi-business operations and role-based access control.

## Module Structure

### 1. Staff Management
**Path:** `/staff-management`
**Overview:** Complete employee lifecycle management from recruitment to separation → Allows create, view, update, and manage employee records with comprehensive profile management, employment history tracking, and organizational structure management.

### 2. Attendance Management
**Path:** `/attendance-management`
**Overview:** Comprehensive attendance tracking and management system → Allows clock in/out functionality, attendance approval workflows, detailed attendance analytics, and export capabilities for payroll processing.

### 3. Leave Management
**Path:** `/leave-management`
**Overview:** Complete leave request and approval system → Allows employees to apply for leaves, managers to approve/reject requests, leave balance tracking, and comprehensive leave analytics with multiple leave types support.

### 4. Claims Management
**Path:** `/claims-management`
**Overview:** Expense claims processing and reimbursement system → Allows employees to submit expense claims, managers to approve/reject claims, multi-currency support, document attachments, and comprehensive claims analytics.

### 5. Event Management
**Path:** `/event-management`
**Overview:** Corporate events and task management system → Allows create and manage company events, assign tasks to employees, track attendance and performance, and generate event analytics reports.

### 6. Work From Home (WFH) Management
**Path:** `/wfh-management`
**Overview:** Remote work request and management system → Allows employees to request work from home, managers to approve/reject requests, WFH analytics, and notification settings for remote work policies.

### 7. Analytics Dashboard
**Path:** `/hr-analytics`
**Overview:** Comprehensive HR analytics and reporting system → Provides detailed insights into attendance patterns, leave utilization, claims analysis, and workforce performance metrics with interactive charts and export capabilities.

### 8. Reports Module
**Path:** `/hr-reports`
**Overview:** Extensive reporting system for HR data analysis → Generates detailed reports on attendance, leave utilization, overtime, working hours, and performance metrics with filtering and export options.

### 9. My HR (Staff Portal)
**Path:** `/my-hr`
**Overview:** Self-service portal for employees → Allows staff to manage their own attendance, leave requests, claims, and view their HR information without admin intervention.

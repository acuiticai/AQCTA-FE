# Operations - Stock Positions Documentation

## 1. Overview

Comprehensive stock management and analytics system → Allows view and analyze stock positions, track inventory levels, monitor stock age, generate stock analytics reports, and manage stock-related purchase and sales contracts across multiple business entities.

## 2. Stock Positions List & Filter

Navigate to Stock Positions → View comprehensive stock dashboard with analytics charts → Table displays stock data with filters (Business, Item Grade, Vendor, Origin, Purchase Date Range, Stock Age) → Use search bar for instant filtering → Apply advanced filters for detailed analysis → View summary statistics and stock overview.

## 3. Stock Analytics Chart

Access Stock Analytics Chart → Interactive chart displaying stock data → Multiple chart types (Bar, Line, Pie) → Configurable axes and metrics → Real-time data visualization → Export chart data → Print chart options → Customizable chart configurations → Group by options (Item, Vendor, Origin, Date).

## 4. Open Purchase Contracts

View Open Purchase Contracts table → Displays all open purchase contracts → Filter by business, vendor, item grade → Search functionality for quick access → View contract details and status → Track purchase contract progress → Export purchase contract data → Generate purchase contract reports.

## 5. Unpurchased Sales Contracts

View Unpurchased Sales Contracts table → Displays all unpurchased sales contracts → Filter by business, customer, item grade → Search functionality for quick access → View contract details and status → Track sales contract progress → Export sales contract data → Generate sales contract reports.

## 6. Stock Filtering & Search
